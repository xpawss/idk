# Псевдо-казино бот для Telegram

Мини-игры на виртуальные монеты 🪙 (никаких реальных денег). Один кошелёк на игрока — и в чате, и в личке.

## Файлы

- `bot.py` — сам бот (команды, база, кнопки)
- `logic.py` — чистая логика: карты, видеопокер, рулетка, слоты, разбор ставок
- `dealer.jpg` — картинка крупье (показывается при раздаче карт в видеопокере)
- `casino.db` — база появится сама при первом запуске

## Установка в Termux

```bash
pkg update && pkg upgrade -y
pkg install python unzip -y
termux-setup-storage            # один раз, разреши доступ к файлам

cp ~/storage/downloads/casino.zip ~
unzip casino.zip && cd casino

pip install -r requirements.txt
```

Если `pip` ругается на `pydantic-core` или `maturin`, поставь сборочные инструменты и повтори (сборка может идти 10–20 минут):

```bash
pkg install rust binutils clang make -y
pip install -r requirements.txt
```

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather): `/newbot` → скопируй токен.
2. Там же: `/mybots` → твой бот → Bot Settings → Group Privacy → **Turn off** (иначе в группе бот не увидит команды), затем добавь бота в чат.
3. Запусти:

```bash
export BOT_TOKEN="123456:ABC..."
export ADMIN_IDS="твой_telegram_id"      # необязательно, для команды !выдать
termux-wake-lock                          # чтобы Android не усыплял Termux
python bot.py
```

Чтобы бот работал, пока Termux свёрнут: `pkg install tmux`, затем `tmux`, запусти бота внутри, отсоединись `Ctrl+B`, потом `D`. Вернуться: `tmux attach`.

Если раньше запускал старую версию, база изменилась: старая таблица сохранится как `users_v1_backup`, а балансы начнутся заново.

## Команды

Все работают и с `/`, и с `!`, можно по-русски. Ставка: `100`, `5к` (5 000), `1.5к`, `2кк` (2 000 000) или `all`.

| Команда | Что делает |
|---|---|
| `!профиль` | профиль: страна, баланс, игры, победы, лучший выигрыш (ответом на сообщение — чужой профиль) |
| `!страна` | выбрать страну (выбор происходит в личке с ботом) |
| `!бонус` | +500 раз в 24 часа |
| `!топ` / `!топстран` | топ игроков чата / топ стран по богатству |
| `!дать 1к` | перевод (ответом на сообщение игрока) |
| `!слоты 100` | 777 → x25, три одинаковых → x8 |
| `!кубики 100` | кубики против бота, победа x2, при ничьей выигрывает бот |
| `!монетка 100 орел` | x1.95 |
| `!покер 1к 29` | видеопокер: ставка на руку и число рук (1–100) |
| `!рулетка 100 red` | общий стол на 20 секунд: red/black/even/odd x2, число x36 |
| `!дуэль 5к` | дуэль на кубиках с другим игроком (банк минус 5%) |

## Видеопокер

Jacks or Better (таблица 8/5). Тебе сдают 5 карт, ты отмечаешь, какие оставить, жмёшь «Раздать». Оставленные карты копируются во все руки, а остальные в каждой руке добираются заново из оставшихся 47 карт. Всего списывается `ставка × руки`, а выплата считается по каждой руке отдельно.

Выплаты (x ставки на руку): роял-флеш 800, стрит-флеш 50, каре 25, фулл-хаус 8, флеш 5, стрит 4, тройка 3, две пары 2, пара валетов и выше 1.

Настройки (стартовые монеты, лимиты, комиссия дуэлей, список стран) лежат в начале `bot.py`.
